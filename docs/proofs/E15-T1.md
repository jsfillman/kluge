# E15-T1

Spec: `docs/spec/checks.md`, heading "Machines".

> A node is in the pool only when it has taint `kluge.dev/pool=reserved:NoSchedule`, label `kluge.dev/gpu=<type>`, and a non-zero `status.allocatable["nvidia.com/gpu"]`. It is healthy when it is not cordoned and it has no other taint. It is free when it is healthy and no Pending or Running pod on that node requests `nvidia.com/gpu`.
