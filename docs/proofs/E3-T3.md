# E3-T3

Spec: `docs/spec/language.md`, heading "Completion".

> After `kluge`, the verbs. After `run`, script files. After `on`, GPU types. After `for`, durations. After `logs` or `cancel`, run names. Shell scripts call `kluge complete`.

## Red

Command: `cargo test -p kluge-cli --test complete`

Exit code: 101

```text
test result: FAILED. 0 passed; 6 failed; 0 ignored; 0 measured; 0 filtered out
```

## Green

Command: `cargo test -p kluge-cli --test complete`

Exit code: 0

```text
test result: ok. 6 passed; 0 failed; 0 ignored; 0 measured; 0 filtered out
```
