# E8-T1

Spec: `docs/spec/checks.md` "When a check runs" and `docs/spec/language.md` "Output and the TUI".

> A local error does not call the server. `--dry-run` checks and does not submit. A clean check posts one Run. An error diagnostic does not. A `pool.waiting` note still posts.

## Red

Command: `cargo test -p kluge-cli --test submit`

Exit code: 101

```text
test result: FAILED. 3 passed; 2 failed; 0 ignored; 0 measured; 0 filtered out
```

Dry-run and the error path already avoided posting. Success and the waiting note did not post yet.

## Green

Command: `cargo test -p kluge-cli --test submit`

Exit code: 0

```text
test result: ok. 5 passed; 0 failed; 0 ignored; 0 measured; 0 filtered out
```

`cargo test -p kluge-cli --test flags` still passes.
