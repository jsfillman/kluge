# E3-T2

Spec: `docs/spec/language.md` "Output and the TUI"; `docs/spec/checks.md` "When a check runs" and "Fixes".

> A local error is printed and the cluster is not contacted. `--dry-run` still checks and does not submit. `--json` prints diagnostics as data. `--strict` turns warnings into errors. `--fix` edits the file and does not submit. A non-interactive `--yes` does not prompt.

