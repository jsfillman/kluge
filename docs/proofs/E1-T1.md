# E1-T1

Spec: `docs/spec/language.md`, headings "Verbs", "Phrases", and "Matching rules".

> Each verb owns its first letter. `ssh` is a whole-word synonym of `attach`. `stop` is a whole-word synonym of `cancel`. Synonyms are not in the prefix tree. `s` and `st` are `status`. `sto` matches nothing.
>
> Phrases have their own prefix tree. `from` is a whole-word synonym of `use`. Leading dashes are ignored on a phrase name, so `--on`, `-on`, `on`, and `o` match the same way.
>
> One name with that prefix wins. Two names with that prefix is an error that lists the names. A whole-word synonym matches only when the token is complete.
