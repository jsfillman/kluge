# E20-T2 A failed machine is not a result

- Status: later

- Depends: E17-T1, E8-T3
- Spec: [roadmap.md](../spec/roadmap.md) "Later, only with a reason" and [decisions.md](../spec/decisions.md) "What we set aside"

## Outcome

The run record can be marked `machine-failed`. `status` and `explain` say the machine failed and the run is not a result. A succeeded run is unchanged. The mark is a field on the `Run`, not a second database.

## Out of scope

The first build. Deciding that a GPU was bad from telemetry.
