## Outcome

`sync` creates the rendered YAML once for an admitted run and creates nothing for a refused run.

`POST /runs` with a spec JSON object returns `{"name":"<name>"}` and creates that YAML. `GET /runs` lists the name. `GET /runs/<name>/logs` returns the stored log. `DELETE /runs/<name>` returns the name and records a delete. A refused spec returns 400 and creates nothing.

The HTTP `Cluster` POSTs each YAML document to the URL the test server records. The test server is not an apiserver.
