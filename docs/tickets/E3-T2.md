## Outcome

- A local error exits non-zero, prints the rendered diagnostic, and does not call a server trait. The test injects a client that panics if called.
- `--dry-run` with only local success still calls the server trait. This ticket's fake server returns no diagnostics. The process prints the resolved sentence and does not print a run id.
- `--json` prints diagnostics as JSON.
- `--strict` turns a warning into a non-zero exit.
- `--fix` edits the file and does not submit.
- `--yes` is ignored when stdin is not a TTY. The test does not allocate a TTY. There is no prompt in the captured output.
- Ctrl-C is not part of this ticket.
