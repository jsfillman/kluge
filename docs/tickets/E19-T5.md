# E19-T5 `outputs` and `fetch`

- Status: open
- Epic: [E19](epics/E19.md)

- Spec: [storage.md](../spec/storage.md) "Commands"

## Outcome

`kluge outputs NAME` prints the object list for that run: path, size, digest. `kluge fetch NAME PATH` writes that one object to a local file and does not download any other key.

Both are exact words. They are not in the prefix tree. Neither submits, cancels, or publishes.
