- Status: open

- Depends: E9-T3

## Outcome

A function, given the run's `into` directory and a listing, returns only the files under `into`. Files outside it, including checkpoints on the rest of the team root, are not in the list. A path that escapes `into` by `..` is dropped and reported with `path.escape`.
