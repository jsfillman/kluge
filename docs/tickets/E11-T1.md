# E11-T1 The binary speaks the sentence

- Status: done
- Epic: [E11](epics/E11.md)
- Depends: E3-T1, E2-T3
- Spec: [decisions.md](../spec/decisions.md) "The core"

## Outcome

`kluge` is not an empty `main`. With no cluster:

- `kluge run train.py on 8 h100 across 4 for 6h` prints the resolved sentence in full words and exits 0. It does not print a run id and it does not contact a server.
- `kluge run train.py for soon` prints a `parse.duration` diagnostic and exits 1.
- `kluge sto` exits 1 and the text names `status` and `cancel`.

## Out of scope

A cluster client, `--fix` from the binary, the TUI, and the menu bar.

## Red

`cargo test -p kluge-cli --test main_core` with `sentence_prints_full_words`, `bad_duration_is_refused`, and `sto_names_status_and_cancel`. The tests call `kluge_cli::main_args`. They fail while `main` is empty and `main_args` does not exist.

## Green

`main` calls `main_args`, writes the text to stdout, and exits with the code. No other verbs are required to succeed.
