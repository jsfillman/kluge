## Outcome

`pending_reason` reads a Kueue Workload and a Pod list and returns one line:

- quota: the Workload is not admitted and the message names the quota
- gang: the Workload is waiting because the group is not all runnable
- image pull: a Pod is `Pending` with a waiting container reason `ImagePullBackOff` or `ErrImagePull`
- pool full: the Workload is admitted and the Pod is `Pending` because it is unschedulable

`explain` uses that line when the record has no other explain line.
