# E19-T3 Object store

- Status: open
- Epic: [E19](epics/E19.md)
- Depends: E19-T1
- Spec: [storage.md](../spec/storage.md) "The object store"

## Outcome

A local S3-shaped store:

- `PUT /objects/{key}` writes one object. The key is the path relative to the team root.
- `GET /objects/{key}` returns that object only.
- `HEAD /objects/{key}` returns size and digest.
- `GET /objects?prefix=` lists keys, sizes, and digests, and does not return bodies.

Fetching one key does not read the rest of the prefix.
