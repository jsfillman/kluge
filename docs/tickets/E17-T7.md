# E17-T7 Directories on disk

- Status: open
- Epic: [E17](epics/E17.md)
- Depends: E5-T2
- Spec: [checks.md](../spec/checks.md) "Files"

## Outcome

`inspect_root(root, dir, into)` stats those paths.

- A directory inside the root that exists and is writable is accepted.
- A missing directory is `path.missing`.
- A directory that exists and is not writable is `path.missing`, and the message says it is not writable.
- A path outside the root, including `..`, is `path.escape`.

The test uses a temporary directory. It does not use a fixture list in place of the stat.
