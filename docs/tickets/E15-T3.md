## Outcome

`poll_once` GETs the node list, the pod list, and the Run list from a base URL.

- The pool becomes the facts from those lists.
- An admitted Run is synced once. A second poll does not create a second YAML.
- A Run whose sentence does not fit the pool creates nothing.

The server in the test is localhost. This does not close E8-T3.
