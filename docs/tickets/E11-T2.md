# E11-T2 Block-quoted scripts

- Status: open
- Epic: [E11](epics/E11.md)
- Depends: E1-T6, E11-T1
- Spec: [language.md](../spec/language.md) "Where a value comes from"

## Outcome

A `*.kluge` file may contain:

```text
run """
module load cuda
torchrun train.py
"""
```

The block is one `run` value. `#` inside it is not a Kluge comment. A line that is only `"""` closes it. A missing close is `parse.run`. A one-line `run train.py --epochs 10` stays argv and does not start a shell.

An `#SBATCH` body is the same kind of script. The known headers stay phrases. The body is not split on whitespace.

The rendered container command for a script is `bash --noprofile --norc /kluge/script`. The script text is the file at that path. An argv run is still the argv, with no shell.

## Out of scope

Mounting the script into a live pod. This ticket covers the parse and the rendered command.
