# E19-T4 Publish the hybrid manifest

- Status: open
- Epic: [E19](epics/E19.md)
- Depends: E19-T2, E19-T3
- Spec: [storage.md](../spec/storage.md) "Hybrid"

## Outcome

`publish` takes a spec, the classified files, and the bytes of the files that are not omitted.

- Cache files are chunked and recorded with `PUT /files/{path}`.
- Object files are put under their path key. The manifest stores the key, size, and digest.
- Omitted files are not read and are not in the manifest.

The run record keeps that manifest. A checkpoint outside `dir` and `into` is omitted.
