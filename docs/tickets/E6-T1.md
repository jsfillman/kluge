# E6-T1 Admission uses `kluge-check`

- Status: open
- Epic: [E6](epics/E6.md)
- Depends: E5-T3
- Spec: [checks.md](../spec/checks.md) "When a check runs"

## Outcome

A `Run` type whose spec fields are only the resolved phrases plus CPU and memory. Admission calls `kluge-check` and returns its diagnostics. It does not reimplement a check. A `Run` that fails a local or cluster check is rejected. The rejection includes the code and the one-line command from the first error suggestion, when one exists.

## Out of scope

A running API server. This ticket tests the admission function in process. The HTTP endpoint is E6-T3.

- `accepts_a_fitting_run`
- `does_not_duplicate_check_logic` is the accept test calling the same function the library tests already cover. Do not copy the pool table into the controller.
