## Outcome

With `KLUGE_API` set to the localhost controller:

- `kluge run train.py on 1 h100 for 1h name sample` prints the sentence and the run name, and the server has the run.
- `kluge status` prints the name.
- `kluge logs sample` prints the log body.
- `kluge cancel sample` returns the name and the server records the delete.
- A bad sentence is refused and the server stores nothing.

With no address, `kluge run` still prints the sentence and does not submit, and `kluge status` still says it needs a cluster.
