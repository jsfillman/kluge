# E1-T2 `on`, `for`, and `with` values

- Status: done
- Epic: [E1](epics/E1.md)
- Depends: E1-T1
- Spec: [language.md](../spec/language.md) "Phrases"

## Outcome

- `for` accepts `6h`, `90m`, and `6 hours` as equal durations. Anything else is a duration error, not a guess.
- `on h100` is one GPU of that type. `on 8 h100` is eight. `on 8xh100` is the same value as `on 8 h100`.
- `with` requires `KEY=VAL` and a non-empty key. The value may be empty. This ticket stores the value. Later tickets keep it out of error text.
- `across` is a positive integer.

## Out of scope

GPU-type existence. That needs a pool fixture in E5.
