# E7-T1 Helm chart

- Status: open
- Epic: [E7](epics/E7.md)
- Depends: E6-T2
- Spec: [cluster.md](../spec/cluster.md) "What the admin does" and "Auth"

## Outcome

`deploy/kluge` renders:

- a namespace
- a service account that is the only subject with the `kluge.dev/pool` toleration
- a Role for researchers that can create and get `Run` objects and cannot create Pods
- a Kueue queue selecting the tainted pool
- the controller Deployment

The chart does not contain a Slinky `NodeSet` or a `slurm.conf`.

## Out of scope

Installing the chart on a cluster. Rendering is the proof.

## Red

There is no unit-test framework required. The red proof is `helm template` failing because `deploy/kluge` does not exist. Record that failure, then add the chart.

## Green

The chart. Values match the settings table in the spec: `pool.gpu`, `team.root`, `team.maxWall`, `team.maxGpus`, `image.allow`, `image.requireDigest`.

## Proof

`docs/proofs/E7-T1.md`

Commands:

- `helm template kluge deploy/kluge --set pool.gpu=h100 --set team.root=/scratch/kernel-search`
- A `rg` over that output showing the taint, the researcher Role, and the absence of `nodeset` and `slurm.conf`.
