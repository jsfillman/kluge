## Outcome

Given a pool fixture of machines with 8 H100s:

- `nods 4` suggests `across` with `auto: true` when the edit distance is 1 and only one phrase is that close.
- `on 32 h100` with no `across`, when 32 is an exact multiple of 8, suggests `on 8 h100` and `across 4` with `auto: true`.
- `on 32 h100` when the fixture pool has 16 GPUs total suggests the largest legal shape with `auto: false`.
- `#SBATCH --exclusive` suggests dropping that line with `auto: true` and a note that reserved nodes are already exclusive.
- `--fix` writes those `auto` edits to the file and does not submit. A second check of the edited file is what the function returns.
- A non-interactive caller never takes a yes/no branch. The library function does not read stdin.
