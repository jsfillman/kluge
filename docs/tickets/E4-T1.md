# E4-T1 Job and JobSet rendering

- Status: open
- Epic: [E4](epics/E4.md)
- Depends: E1-T4
- Spec: [cluster.md](../spec/cluster.md) "What a run becomes"

## Outcome

A pure function renders YAML.

- `across` 1 renders one `batch/v1` Job.
- `across` greater than 1 renders a JobSet whose pod count equals `across`.
- Image, argv, GPU count, active deadline, working directory, env, and the team-root mount come from the spec.
- CPU and memory from a translated `#SBATCH` file are requests on the container when present.

## Out of scope

Talking to an API server. Kueue labels may be present only if the spec's cluster page requires the queue to admit the job. If you add them, cover them in the fixture.

## Red

## Green

The renderer.
