## Outcome

A local chunk service speaks the HTTP in the spec.

- `PUT /chunks/{digest}` stores bytes. A second put of the same digest is the same chunk.
- A `Content-Range` continues a chunk that stopped early. The finished digest matches the whole chunk.
- `GET /chunks/{digest}` returns that chunk.
- `PUT /files/{path}` records digest, size, and mode.
- `GET /files?prefix=` lists metadata and does not return bodies.

The test server is in-process. There is no POSIX lock on the wire.
