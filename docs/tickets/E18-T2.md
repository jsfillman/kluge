# E18-T2 Explain, debug, and attach on the API

- Status: open
- Epic: [E18](epics/E18.md)
- Depends: E18-T1, E9-T2, E9-T3, E13-T4
- Spec: [language.md](../spec/language.md) "Verbs" and "Output and the TUI"

## Outcome

With `KLUGE_API` set:

- `kluge explain NAME` prints the run's explain line in the diagnostic shape.
- `kluge debug` returns the rewritten sentence `on 1 <type> across 1` and does not submit.
- `kluge attach NAME` returns the pod name. It does not open a byte stream.

Without an address, the three verbs still say they need a cluster.

## Out of scope

A live `kubectl exec`. That waits for a cluster.
