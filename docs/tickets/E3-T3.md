# E3-T3 Completion candidates

- Status: open
- Epic: [E3](epics/E3.md)
- Depends: E3-T1
- Spec: [language.md](../spec/language.md) "Completion"

## Outcome

A pure function returns completion candidates:

- After `kluge`, the verb names.
- After `run`, files in a supplied directory listing ending in `.py`, `.sh`, `.kluge`, and `.sbatch`.
- After `on`, GPU types from a supplied pool list.
- After `for`, `30m`, `6h`, and `6 hours`.
- After `logs` or `cancel`, run names from a supplied list.

`kluge completion bash`, `zsh`, and `fish` print a script that calls back into `kluge complete`. The test asserts the script contains the binary name and the shell. It does not install the script.

## Out of scope

`kluge completion install` writing into a home directory. That can wait until a ticket asks for it.
