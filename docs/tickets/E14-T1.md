# E14-T1 Menu layout

- Status: done

- Depends: E10-T2
- Spec: [language.md](../spec/language.md) "Menu bar"

## Outcome

`render` of a menu matches the spec's text shape:

- no rows prints `kluge 0`
- one row starts selected, with its explain line and output names under it
- two rows start unselected
- choosing a row marks it and shows its explain line
- the text has no submit, cancel, or sync item

`kluge menu` prints `kluge 0`. `kluge menu --screen FILE` prints the menu for that JSON. No window.
