# E20-T1 Borrow idle Slinky nodes

- Status: later
- Epic: [E20](epics/E20.md)
- Depends: E8-T3
- Spec: [roadmap.md](../spec/roadmap.md) "Later, only with a reason" and [cluster.md](../spec/cluster.md) "Slinky beside Kluge"

## Outcome

A controller can untaint an idle Slinky node into the Kluge pool when Slurm's pending work is below a configured floor, and taint it back when Slurm has pending work. A running Slurm job is never preempted. The floor and the grace period are admin settings.

## Out of scope

The first install. Automatic borrowing is not part of install.

## Red

`cargo test -p kluge-controller --test borrow` with recorded node and Slurm-pending fixtures. A live borrow waits until E8-T3 has a cluster.

## Green

The decision function. It does not call a live Slurm.
