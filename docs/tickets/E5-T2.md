# E5-T2 Path checks

- Status: open
- Epic: [E5](epics/E5.md)
- Depends: E5-T1
- Spec: [checks.md](../spec/checks.md) "Files"

## Outcome

Against a fixture filesystem with a team root and one symlink that escapes it:

- `dir` or `into` that resolves outside the root, including through `..` or the symlink: `path.escape`, `auto: false`
- A path inside the root that is not present: `path.missing`
- A path inside the root that exists: no diagnostic

## Out of scope

A real mount. The fixture is an in-memory map of paths.
