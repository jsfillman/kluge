# E17-T3 GPU prefix

- Status: open
- Epic: [E17](epics/E17.md)
- Depends: E15-T1
- Spec: [language.md](../spec/language.md) "Abbreviations beyond the grammar"

## Outcome

`resolve_gpu_prefix` takes the parsed `on` value and the pool's kinds.

- `on 8 h` with only `h100` becomes `on 8 h100`.
- `on h` with only `h100` becomes one `h100`.
- `h100` and `h200` both matching `h` is `parse.ambiguous` and lists both. No rewrite.
- A kind that matches nothing is `pool.type`.

Admit uses this before the shape check.
