# E1-T1 Prefix matching

- Status: done
- Epic: [E1](epics/E1.md)
- Depends: E0-T1
- Spec: [language.md](../spec/language.md) "Verbs", "Phrases", "Matching rules"

## Outcome

Two prefix tables, verbs and phrases. Unique first letters as the spec lists them. Whole-word synonyms `ssh`, `stop`, `from`, and `as` match only when the token is complete. `s` and `st` are `status`. `sto` matches nothing. `a` is `attach` in the verb table and `across` in the phrase table. Dashes on a phrase token are ignored (`--on`, `-on`, `on`, `o`).

An ambiguous prefix returns the matching names and does not pick one. Edit distance is not used to select a match.

## Out of scope

Parsing values, files, diagnostics text, and the CLI binary.
