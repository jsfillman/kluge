# E13-T1 Check and admit over HTTP

- Status: open
- Epic: [E13](epics/E13.md)
- Depends: E12-T7, E6-T3
- Spec: [cluster.md](../spec/cluster.md) "The Kluge API"

## Outcome

The controller answers on a localhost port:

- `POST /check` with `{"text":"<phrases>"}` returns diagnostic JSON.
- `POST /admit` with an AdmissionReview of a `Run` whose `spec.text` is the sentence returns an AdmissionReview. A refusal's `status.message` starts with the code.

No apiserver.
