## Outcome

`kluge files DIR` fills `DIR` from the cache. A file already in the local chunk cache is not downloaded again. A changed file is written back as a new chunk and a new file record. Unchanged files keep their digest.

The test uses two temporary directories. It does not mount a filesystem.
