## Outcome

Submit calls `fill_export` with the environment it is given before it posts the spec. `--export=FOO,BAR` puts `FOO`'s value on the pod and skips `BAR` when `BAR` is unset. `--export=NONE` adds nothing. `--export=ALL` is still refused.

The test passes the environment in. It does not read the process environment.
