## Outcome

A `Diagnostic` serializes to the JSON object in the spec, including `code`, `severity`, `message`, `span`, `notes`, and `suggestions[].auto`, `replacement`, and `command`. Unknown fields from a future server are ignored on read so an old CLI does not crash. Codes are the strings in the spec's table, as an enum that cannot emit any other string.
