# E19-T7 Mount

- Status: blocked-on-display
- Epic: [E19](epics/E19.md)
- Depends: E19-T6
- Spec: [storage.md](../spec/storage.md) "The cache"

## Outcome

A FUSE or macOS file-provider mount of the cache. Object names appear as files. Opening one object fetches that object and no other. The mount is the same protocol as `kluge files`.

This stays blocked until the proof is a mount exercised on a machine that can mount one. A fake filesystem does not close it.

## Out of scope

NFS. sshfs. A kernel of our own.

## Red

Not a unit test. The red state is the absence of a mountable machine.

## Green

The mount, plus a transcript of listing the working tree and opening one object.
