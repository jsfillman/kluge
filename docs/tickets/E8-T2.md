# E8-T2 Status, logs, and cancel

- Status: open
- Epic: [E8](epics/E8.md)
- Depends: E8-T1
- Spec: [language.md](../spec/language.md) "Verbs", "Abbreviations beyond the grammar"

## Outcome

Against the fake server:

- `kluge status` prints a table of the server's runs.
- `kluge status ab` selects the single matching name and fails with `parse.ambiguous` when two match.
- `kluge logs NAME` prints the server's log body.
- `kluge cancel NAME` sends one cancel and prints the name.
- None of these create a Pod.

Ctrl-C during `logs` stops the stream in the test by dropping the reader. The fake server records that cancel was not called.

## Out of scope

A TUI. An exec stream.
