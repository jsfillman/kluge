# E6-T3 Check endpoint

- Status: open
- Epic: [E6](epics/E6.md)
- Depends: E6-T1
- Spec: [checks.md](../spec/checks.md) "When a check runs"

## Outcome

`POST` of a normalized spec returns the diagnostic JSON array from `kluge-check`, with the same bytes the renderer fixture uses for `pool.shape` when that is the failure. An empty array is HTTP 200. A body that is not the spec is HTTP 400 and not a new diagnostic code.

The endpoint does not create a Pod or a Job.

## Out of scope

Authentication transport. The handler takes a caller identity already parsed by a layer this ticket may stub.

## Red

`cargo test -p kluge-controller --test check_endpoint`

## Green

The smallest HTTP server that mounts the handler. Pick one Rust HTTP crate and do not add a second.
