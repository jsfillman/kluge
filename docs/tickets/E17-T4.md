- Status: open

- Spec: [language.md](../spec/language.md) "Completion"

## Outcome

`complete` gains the cases the spec names that the current tests do not:

- After `across`, the machine counts that fit the reserved pool passed in by the caller.
- After `name`, `attach`, and `explain`, the caller's run names. `logs` and `cancel` already return them.
- After `on`, counts and then the GPU types. A count already typed still offers the types.
- The completion scripts call `kluge complete` with the words already typed, so the binary is the completer.

## Out of scope

Installing the scripts into a real shell rc file beyond E13-T5.
