# E2-T3 Local checks

- Status: open
- Epic: [E2](epics/E2.md)
- Depends: E1-T6, E2-T2
- Spec: [checks.md](../spec/checks.md) "Local checks" and the codes table

## Outcome

Local checks emit these codes and do not contact a cluster:

| Case | Code |
| --- | --- |
| Unknown phrase | `parse.unknown` |
| Ambiguous prefix | `parse.ambiguous` |
| Duplicate phrase | `parse.duplicate` |
| Missing `run`, or local script path that is not a file | `parse.run` |
| Bad duration | `parse.duration` |
| Refused `#SBATCH` directive | `parse.sbatch` |

`with` values do not appear in the rendered diagnostic. A missing `for` is `parse.duration` when no layer sets it, and is not an error when the `Klugefile` sets it.

## Out of scope

`pool.*`, paths on the cluster, images, `--fix`.

## Red

`cargo test -p kluge-check --test local_checks`, one test per row above, plus `with_value_not_in_text` and `klugefile_for_satisfies_duration`.

## Green

The local check pass over a resolved or failed parse.
