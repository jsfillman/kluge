## Outcome

`kluge run` against the API prints the sentence and the name, then follows the log. Bytes already written are printed. `on_interrupt` stops the follow before the next chunk. Cancel is not called. The job stays.

## Out of scope

A live Pod log. The test server writes the chunks.
