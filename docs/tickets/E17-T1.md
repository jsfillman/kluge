# E17-T1 Status table

- Status: open
- Epic: [E17](epics/E17.md)
- Depends: E16-T2
- Spec: [language.md](../spec/language.md) "Output and the TUI"

## Outcome

A stored run has a name, a state, a GPU count, an age in seconds, and one explain line. A new submit starts at `pending`.

`kluge status` prints a table with the columns `NAME`, `STATE`, `GPUS`, and `AGE`. `kluge status NAME` prints that one row and the explain line. A prefix that matches two names is `parse.ambiguous`. A prefix that matches none is an unknown run.

## Out of scope

Reading the state from a live Pod. That is E18-T3.

## Red

`cargo test -p kluge-controller --test record` and `cargo test -p kluge-cli --test status_table`

## Green

The stored fields, the table, and `GET /runs` returning those columns.
