# E4-T2 Fixed pod template

- Status: open
- Epic: [E4](epics/E4.md)
- Depends: E4-T1
- Spec: [cluster.md](../spec/cluster.md) "What a run becomes", [checks.md](../spec/checks.md) "The Pod template is fixed"

## Outcome

The rendered pod has no `privileged`, no `hostNetwork`, no `hostPID`, no `hostIPC`, no extra capabilities, and no volume except the team-root mount. The container command is the `run` argv. It is not `sh -c`. The toleration for `kluge.dev/pool=reserved:NoSchedule` is present. A node selector on `kluge.dev/gpu` is present.

The renderer has no parameter that could add those forbidden fields.

## Out of scope

The webhook that rejects a mutated Pod. That is E6-T1.
