# E9-T3 `debug` and `attach`

- Status: open
- Epic: [E9](epics/E9.md)
- Depends: E8-T2
- Spec: [language.md](../spec/language.md) "`debug`" and `attach`

## Outcome

`kluge debug train.py on 8 h100 across 4` prints the rewrite to `on 1 h100 across 1` and submits that spec through the same client as `run`. The image and argv are unchanged.

`kluge attach NAME` requests an exec in the run's pod and nowhere else. The test asserts the exec target is that pod. It does not open a shell. `ssh` as a whole word is the same request. `ss` is not.
