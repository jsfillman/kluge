# E5-T1 Pool checks

- Status: open
- Epic: [E5](epics/E5.md)
- Depends: E2-T1, E4-T1
- Spec: [checks.md](../spec/checks.md) "Server checks" and the situation table

## Outcome

`check_pool(spec, view) -> Vec<Diagnostic>` over a fixture:

- GPU type missing: `pool.type`
- Count that no machine has: `pool.shape`, with the auto suggestion from E2-T4 when the GPU count is an exact multiple
- Shape larger than the pool or the quota: `pool.capacity`, `auto: false`, suggesting the largest legal shape
- Shape fits existing healthy machines but not the free ones: no error, one note `pool.waiting`
- Healthy means not cordoned, Kluge taint only, GPUs allocatable
