- Status: open

- Spec: [decisions.md](../spec/decisions.md) "Language"

## Outcome

A stable-toolchain Cargo workspace with three library/binary crates and no product behavior:

- `kluge-check` library
- `kluge-cli` binary, name `kluge`
- `kluge-controller` library

`cargo test --workspace` exits 0. The binary's `--help` is allowed to be clap's default. It must not parse phrases yet.

## Out of scope

Grammar, diagnostics, Kubernetes clients, Dockerfiles, Helm, and edits under `cli/`.

## Red

Add `kluge-check/tests/workspace.rs` that calls a public function `kluge_check::crate_name() -> &'static str` and asserts it equals `"kluge-check"`. Run `cargo test --workspace`. The compile failure is the red result. Record it before adding the function.

## Green

The workspace, the function, and empty `fn main()` in the two other crates. No other public API.
