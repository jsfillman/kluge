- Status: open

## Outcome

Given an accepted `Run`, the reconciler builds the same YAML E4-T1 and E4-T2 already assert, and records that YAML as the object it would create. The test uses a fake client that stores creates. A rejected `Run` creates nothing. Reconciling twice does not create a second Job.
