# E15-T1 The pool from node and pod lists

- Status: done
- Epic: [E15](epics/E15.md)
- Depends: E13-T2, E5-T1
- Spec: [checks.md](../spec/checks.md) "Machines"

## Outcome

`nodes_from` reads a Kubernetes node list and a pod list.

- A node with the Kluge taint, label `kluge.dev/gpu=h100`, and allocatable `8` is one healthy free fact.
- A node without that taint is ignored.
- A cordoned node, or one with another taint, is unhealthy.
- A Pending or Running pod on the node that requests `nvidia.com/gpu` makes it busy. A Succeeded pod does not.
- `apply_pool` replaces the controller's node list. A GPU sentence against the empty list is `pool.type`. The same sentence against the loaded list is accepted.
