# E5-T3 Image, name, and auth

- Status: open
- Epic: [E5](epics/E5.md)
- Depends: E5-T1
- Spec: [checks.md](../spec/checks.md) "Identity", "Ceilings", "Image", and the codes table

## Outcome

Over a fixture view:

- `:latest` with `requireDigest` false is a warning.
- An unpinned tag with `requireDigest` true is `image.denied`.
- A repository outside the allowlist is `image.denied`.
- A pull-failure flag on the view is `image.pull`.
- A name that fails `^[a-z][a-z0-9-]{0,62}$` is `name.syntax`.
- A name in the view's live set is `name.taken`, with a suffixed suggestion and `auto: false`.
- A team the caller does not belong to is `auth.team`.
- A missing caller is `auth.identity`.
- A parsed `for` above the team ceiling is `time.ceiling`.

No new codes.

## Out of scope

A registry client. The view carries allowlist, digest policy, pull result, memberships, and the ceiling.
