## Outcome

On a cluster with one tainted GPU node, a researcher credential, and the chart installed:

1. `kluge run` of a one-GPU command reaches a succeeded Pod.
2. `kluge logs` shows the process output.
3. `kluge cancel` of a second run stops it.
4. A `#SBATCH` file submits.
5. A file with `on 32 h100` does not submit, and `--fix` rewrites it when the machine has eight GPUs.

This ticket stays `blocked-on-cluster` until those commands run against that cluster. A fake server does not close it.
